## Why: most likely floating point, not code

All seeds are fixed and every package is pinned, so the same platform reproduces exactly (local reruns: 0 of 122 differ). Across platforms,
the BLAS library (Apple Accelerate on arm64 vs OpenBLAS on x86_64) and SIMD paths change the last bits of sums inside scikit-learn's
calibration and logistic fits. Those bits move a few bootstrap CI ends and predicted risks in the third decimal. To reproduce the committed
files bit for bit, run on macOS arm64; on Linux x86_64 expect these differences.
